# 🗂 AmiralidlbWOrld · HQ

### 📌 Pinned projects. 🗂 Every repo. 🌓 Light & dark.

A personal HQ site that showcases my pinned projects and lists every repository on my GitHub account, in a single dependency-free HTML file.

[🇬🇧 English](#english) • [🇮🇷 فارسی](#فارسی)

## 🌐 English

### 🚀 Live Demo

**👉 [amiralidlb93-hash.github.io](https://amiralidlb93-hash.github.io)**

### ✨ Features

- 📌 **Pinned section** with cards for my best projects
- 🗂 **All Projects** loaded live from the GitHub API, with language filters
- 🔄 **Descriptions stay in sync** with the repositories automatically
- 🌓 **Light / dark theme** that follows your system and can be toggled
- 📱 **Fully responsive**, from phones to wide screens
- ⚡ **No dependencies**, no build step, just `index.html` and `style.css`

### 🛠 Tech

HTML · CSS · JavaScript

### 📁 Structure

```
.
├── index.html
├── style.css
└── README.md
```

### 💻 Run locally

```bash
git clone https://github.com/amiralidlb93-hash/amiralidlb93-hash.github.io.git
cd amiralidlb93-hash.github.io
```

Open `index.html` in your browser.
